# 当前结论

自动化实验能否规模化，通常不只取决于候选生成速度，更取决于目标能否度量、评估器是否足够快且与真实目标一致。使用学习得到的近似评估器可以扩大搜索，但必须用真实评估持续校准，否则系统会高效地优化代理指标而非真实结果。

# 判断依据

来源对谈把自动化科学方法描述为“提出候选—实现实验—评估—保留结果—继续搜索”的循环，并强调高层目标需要被拆成可独立探索、再重新组合的子问题。这个循环只有在评价成本可接受时才能高频运行。

对谈用量子化学模拟举例：从昂贵模拟输出训练快速近似模型，可显著降低筛选候选的成本。该具体倍数和误差水平未在本次外部核验，但它说明了一个更一般的系统关系：当生成器加速后，瓶颈会迁移到评估、选择和真实性校验。

本知识节点进一步引入代理指标偏移的边界。快速评估器不是 Ground Truth；候选分布发生变化时，近似模型可能在最需要区分的区域失准。

# 应用方式

搭建自动化实验系统时，可采用分层评估：

1. 先定义真实目标、硬约束和不可接受结果；
2. 用便宜规则或近似模型做大规模初筛；
3. 对高分、边界和随机样本运行更昂贵的真实评估；
4. 持续记录近似评估与真实结果的误差，并监测分布漂移；
5. 只有通过真实评估的结果才能进入生产、科学结论或下一轮训练数据；
6. 用单位算力、时间或实验成本带来的“有效发现数”衡量系统，而不是只统计生成数量。

若任务无法给出稳定评估标准，优先做辅助探索和人工决策支持，不要伪装成全自动发现系统。

# 适用边界

- Goodhart 效应：一旦代理指标成为优化目标，系统可能找到评估器漏洞。
- 近似评估器在训练分布内准确，不代表在新颖候选或极端区域仍准确。
- 科学发现、组织决策和社会影响通常包含多个冲突目标，单一分数会隐藏价值取舍。
- 快速评估可能提高实验吞吐，也会放大错误目标、数据偏差和资源消耗。
- 医疗、安全、法律和重大财务领域不能仅凭代理评估器自动推广结果。

# 不同观点与冲突

有些任务的主要瓶颈仍是候选生成、实验执行、数据获取或现实世界周期，而不是评估器。应通过端到端耗时和失败分布定位瓶颈，不能预设所有系统都应优先优化评估。

更昂贵的真实评估也不一定等于更正确；若真实指标本身定义不完整，就需要先解决目标与测量设计，而不是只提高评估速度。

# 我的认知
