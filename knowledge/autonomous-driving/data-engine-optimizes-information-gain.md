# 当前结论

物理 AI 的数据优势不应只用总里程、总时长或总字节衡量。更有效的数据闭环应围绕当前模型缺口选择高信息增益样本，例如新颖或稀少场景、模型与人类行为分歧、人工接管、低置信度、近失效和分布漂移，并通过可追溯标注、版本化数据集和闭环回归验证这些样本是否真正改善目标任务。

# 判断依据

来源转述 Tesla 的数据选择方法：随机驾驶视频中大量片段高度重复，优先采集典型或稀少场景，以及模型建议动作与人类实际动作不一致的片段。这个机制与 active learning、disagreement mining 和 hard-example mining 相符：把有限存储、标注和训练预算投入模型尚未掌握的区域。

知识库不接受“规模消解边缘案例”的绝对表述。大车队提高发现概率，但真正风险仍受地理、气候、道路参与者、传感器版本、驾驶政策和采样触发器影响；极罕见但高损失的事件也可能长期缺样本。

来源还称云端教师模型和离线重建可生成 3D 监督。知识库把它视为扩大标签能力的方法，而不是 Ground Truth：教师偏差、时序重建误差和分布盲区会被蒸馏给车端模型，必须保留标签来源、置信度和抽检结果。

本次未核验 Tesla 车队规模、数据量、随机样本无效比例或离线标注性能，结论仅保留产品无关机制，置信度为 low。

# 应用方式

建立数据闭环时，至少维护五类触发器：

1. 行为分歧：模型动作与人类动作、接管或规则约束显著不同；
2. 认知不确定：模型低置信度、多个模型分歧或感知与预测不一致；
3. 新颖覆盖：新地理、天气、道路结构、对象组合、传感器或软件版本；
4. 风险事件：碰撞、近碰、急制动、危险侵入、异常 fallback 和用户投诉；
5. 性能漂移：线上分布、失败类型或关键指标相对基线发生变化。

每个样本应记录触发原因、采集版本、权限与隐私状态、标注来源、标签置信度、去重关系和进入哪些训练或评测集合。训练后按触发类别回看收益，并检查是否只改善被采样区域、同时伤害常见场景。

# 适用边界

- 人类操作并非永远正确，模型—人类分歧是调查信号，不是自动标签。
- 只挖难例会扭曲数据分布；训练集仍需保留代表性常见场景和明确采样权重。
- 教师模型生成的标签需要抽检、交叉传感器或几何一致性验证，不能被称为无误差真值。
- 稀有场景的合成、仿真与现实采集各有分布差异，应组合验证。
- 数据采集受隐私、用户授权、地域法规、带宽和保留期限约束，信息增益不能凌驾于合规。

# 不同观点与冲突

大规模随机采样能提供无偏分布基线，而主动采样更快暴露模型缺口；两者不是替代关系。代表性样本用于校准整体分布，高信息增益样本用于针对性学习，独立固定评测集用于判断泛化，三者应分开管理。
